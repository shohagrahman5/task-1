# CodeAlpha Basic Chatbot

A beginner-friendly rule-based chatbot built with Python. It uses predefined rules and replies; it does not use AI or an online service.

## Features
- Responds to greetings such as `hello`, `hi` and `hey`.
- Answers a few predefined questions.
- Provides a help response.
- Ends the conversation when the user types `bye`, `goodbye`, `exit` or `quit`.
- Gives a default response to unknown messages.

## Requirements
- Python 3
- No external libraries are required.

## How to run
1. Open this folder in VS Code.
2. Open the VS Code terminal.
3. Run:

   ```bash
   python main.py
   ```

   On some Windows installations, use `py main.py`.

4. Type a message and press Enter.
5. Type `bye` to close the chatbot.

## Concepts used
Functions, strings, `if-elif-else`, loops and input/output.
